# Ctt Web

Todolist dan pencatatan keuangan - versi web.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Jalankan development server:
```bash
npm run dev
```

3. Buka http://localhost:3000

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Firebase (Auth + Firestore)
